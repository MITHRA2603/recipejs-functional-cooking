
# RecipeJS - Your Functional Cooking Companion

## About the Project
RecipeJS is a recipe companion application built using HTML, CSS, and JavaScript.

## Features
- Displays 8 recipe cards dynamically
- Shows recipe preparation time
- Displays difficulty badges
- Responsive card layout
- Hover animations

## Technologies Used
- HTML5
- CSS3
- JavaScript ES6

## Part 1
Created the basic structure and dynamically rendered recipe cards using JavaScript array methods.
